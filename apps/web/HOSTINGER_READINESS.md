## How Build Works

1. Hostinger runs `npm install` in `./` (installs old demo deps from root `package.json`)
2. Hostinger runs `npm run build` (root) → executes `node scripts/hostinger-build.mjs`
3. The script:
   - Runs `npm install` inside `apps/web` (Next.js dependencies)
   - Runs `npm run build` inside `apps/web` (Next.js production build)
   - Copies `apps/web/.next` → `./.next` (Hostinger detects output at root level)
4. Hostinger should run `npm start` → `npm --prefix apps/web run start` → `next start`

## 403 Diagnosis

Build ✅, 403 at runtime. Most likely cause:

**Hostinger is not starting the Node.js server.** After build, Hostinger may:
- Try to serve `.next` as static files (no index.html → 403)
- Fail to auto-detect the server entry point

**Local verification:** `npm run build && npm run start` from root → 200 ✅

**Required action in Hostinger:**

1. Open `hPanel → Hosting → Manage → Node.js` (or **Advanced → Node.js**)
2. Verify Application mode = **Node.js** (not PHP)
3. Set **Start command / Entry point** explicitly to: `npm run start`
4. If there's a "Run command" or "Application command" field: enter `npm start`
5. Save and **Restart** the application (not just redeploy)

If the hPanel does not have Node.js settings, the plan may not support Node.js runtime — see options below.
